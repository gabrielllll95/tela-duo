Tela Duo

Compartilhamento de tela simples, só para duas pessoas.

Crie um código e envie-o para a outra pessoa.
Tela da outra pessoaAguardando
Sua telaNão compartilhando

Dica: os dois participantes precisam usar o mesmo código. Clique em “Compartilhar tela inteira” e escolha “Tela inteira” no aviso do navegador. O navegador exige HTTPS quando o site estiver publicado (localhost funciona sem HTTPS). Compartilhe o código apenas com quem você quer que entre.
